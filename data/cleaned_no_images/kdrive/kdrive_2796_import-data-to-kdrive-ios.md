# Import data to k Drive (iOS)

Source: https://www.infomaniak.com/en/support/faq/2796/import-data-to-kdrive-ios

---

This guide explains how to transfer files from an i Phone to an [k Drive](https://infomaniak.com/gtl/kdrive) Infomaniak.

### Prerequisites

- Have a [k Drive](https://infomaniak.com/gtl/ksuite.kdrive) or [k Suite](https://infomaniak.com/gtl/ksuite) offer.
- [Install](https://ksuite.infomaniak.com/all?global-settings=user-apps) the mobile app **k Drive** (application for iOS smartphone or tablet).

## Manually send data to k Drive iOS (i Phone, i Pad)

To do this:

1. Select the data you want to share on k Drive.
2. Click on the i Phone share icon:

3. Choose k Drive from the options offered:

4. Select the k Drive and the backup location - if this does not suit you, press it to change the storage folder:

5. Choose another folder or **create a new folder**:

6. Determine the type of folder to create (shared folder with k Drive users or personal & private folder):

7. Name the folder, choose the possible shared access and then press the blue button to create the folder:

8. Press the newly created folder to select it as the location:

9. Create a possible subfolder in it or **validate** the chosen location with the blue button:

10. Press the blue button to start **sending** your files to k Drive:

11. It is possible to follow the progress of the transfer to k Drive:

12. The upload takes place in the background:

Once the files are uploaded, you will find them on all devices connected to k Drive…

- … instantly on the Web app **k Drive** (online service [ksuite.infomaniak.com/kdrive](https://ksuite.infomaniak.com/kdrive)).
- … after downloading the list of these new files to the devices where the **k Drive** desktop app (desktop application on macOS / Windows / Linux) is installed.
