# Import data from k Drive to another k Drive

Source: https://www.infomaniak.com/en/support/faq/1908/import-data-from-kdrive-to-another-kdrive

---

This guide explains how to copy within the desktop app **k Drive** (desktop application on macOS / Windows / Linux) data from a k Drive **to which your Infomaniak user has access** to another k Drive **to which the same Infomaniak user has access**.

### Preamble

- To be the user of multiple Organizations, you must [have been added to them](https://www.infomaniak.com/en/support/faq/1404) and have obtained access rights to the respective k Drives. For example, if the user abc@domain.xyz has within their Organization "ABC" a k Drive "ABC" and is invited to the Organization "VWX" which has granted them access to the k Drive "VWX", they will see 2 k Drives on kdrive.infomaniak.com and will be able to send data from one to the other in 1 click.
- Without being a user of multiple Organizations, it is also possible to copy data but [only by importing an entire k Drive](https://www.infomaniak.com/en/support/faq/2557), without being able to choose specific data.

## Copying data between multiple k Drives

To copy a folder or file to the other k Drive to which you have access from the same user account:

1. [Click here](https://kdrive.infomaniak.com) to access the Infomaniak **k Drive** Web app (online service [kdrive.infomaniak.com](https://kdrive.infomaniak.com/)).
2. Check or select the relevant k Drive in the dropdown menu of the left sidebar.
3. Select, if necessary, the other k Drive from which you want to copy files:

4. Right-click or click on the action menu **⋮** to the right of the folder or file you want to copy to the other k Drive.
5. Click on **Organize**.
6. Click on **Copy to another k Drive**.
7. Choose the relevant k Drive from the list visible in this same dropdown menu:

8. Choose the destination location (knowing that the shared folder ("**Organization Folders**") cannot receive a file or folder at its root but you can create a subfolder using the **appropriate icon** if the user has the rights).
9. Click on the blue button to start the copy:

> **Note:** The copy is not instantaneous or immediate - please wait several minutes!

If you wish to import all the data contained on the other k Drive **in one go**, refer to [this other guide](https://www.infomaniak.com/en/support/faq/2406) and choose **k Drive** at point **6**.
