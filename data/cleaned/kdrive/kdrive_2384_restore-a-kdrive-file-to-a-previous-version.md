# Restore a k Drive file to a previous version

Source: https://www.infomaniak.com/en/support/faq/2384/restore-a-kdrive-file-to-a-previous-version

---

This guide explains how to use the file history or versioning on [k Drive](https://infomaniak.com/gtl/kdrive).

### Preamble

- This feature is very useful for recovering information that has been deleted or modified by a third party within a collaborative file.
- Infomaniak keeps in the version history **a backup of all changes made to files** on k Drive.
- You can choose to keep certain versions indefinitely.

## Manage previous file versions

To access k Drive:

1. [Click here](https://ksuite.infomaniak.com/kdrive) to access the k Drive Infomaniak Web app (online service [ksuite.infomaniak.com/kdrive](https://ksuite.infomaniak.com/kdrive)).
2. Navigate through the k Drive directory that appears.
3. Right-click **on the desired file.**
4. Click on **Version History**:

![image](https://faq.storage5.infomaniak.com/cd81dfd29656295847cbabe00aecce7fa8977879.png)

The different versions of the file are listed in reverse chronological order.

You can delete all versions of this file using the button.

Otherwise, a menu on the right of each version allows you to:

![image](https://faq.storage5.infomaniak.com/e8916a6e089cd025330102aa6e0d292bb636c3b5.png)

- ... download the file in its state at the date/time of the selected version,
- ... keep it indefinitely: the version will be kept after the standard retention period,
- ... create a new file on k Drive from this version,
- ... delete the version: allows you to erase this version only.

You can also access **all versions of all your files**...

1. … from the left menu **Manage storage space**
2. … open the dropdown menu to select **File versions:**

> **Note:** It is also possible to restore a [previous version of the entire organization of your files](https://www.infomaniak.com/en/support/faq/1838) on k Drive.
