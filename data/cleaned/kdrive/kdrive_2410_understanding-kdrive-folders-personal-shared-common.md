# Understanding k Drive folders (personal, shared, common)

Source: https://www.infomaniak.com/en/support/faq/2410/understanding-kdrive-folders-personal-shared-common

---

This guide details the structure of [k Drive](https://infomaniak.com/gtl/kdrive) by Infomaniak: online interface, menus for managing and finding your shares, utility and meaning of default folders, etc.

### Preamble

- This guide applies to the Web app **k Drive** (online service [ksuite.infomaniak.com/kdrive](https://ksuite.infomaniak.com/kdrive)).
- The desktop app **k Drive** (desktop application on macOS / Windows / Linux) is not directly concerned (and will not display certain elements). The mobile app (application for iOS / Android smartphone or tablet) is similar in terms of menu organization (with a few singularities such as offline files, for example).
- The **Shared** folders and the **Shares** menu are only visible with [certain multi-user offers](https://infomaniak.com/gtl/ksuite.kdrive.prices).
- **Do not rename and/or move the default-created folders** either on the Web version and even less locally, as this causes synchronization issues.
- To quickly access the different functionalities/operations, right-click on your files.

## 3 main elements

The k Drive interface offers a left-side menu that guides you to the k Drive data, including these 3 main elements:

### 1. Organization folders: common to the collaborators of your Organization

This folder displays the folder tree shared automatically with certain or all users of the same k Drive; if they contain documents, they will be displayed in the center of the interface:

![image](https://faq.storage5.infomaniak.com/48112985213639be133d8b6abc1a5b6aebeb8d78.png)

If you create a new folder here, you can choose to share it with the entire Organization (all k Drive users) or only a few users / work teams who will then need to **request access** if necessary:

![image](https://faq.storage5.infomaniak.com/ae12e45f261de0c91146418eb957e63895e0b5ba.png)

### 2. My folder: default personal & private folder

This folder displays the folder tree specific to the user themselves: indeed, each k Drive user has their own personal space that will not be automatically shared with other users of the same k Drive:

![image](https://faq.storage5.infomaniak.com/f54ceed70ad2e6d6759694a538f55344acbaca41.png)

Any documents will be displayed in the center of the interface.

### 3. Shares

The **Shares** menu leads to 4 sub-menus displayed in the left-side menu:

1. The elements shared with you by other k Drive users, among the k Drives you have access to with your login identifier
2. The elements that you [share with other users](https://www.infomaniak.com/en/support/faq/2382)
3. The elements that you have shared by creating a [public share link](https://www.infomaniak.com/en/support/faq/2382)
4. The [drop boxes](https://www.infomaniak.com/en/support/faq/2386)

![image](https://faq.storage5.infomaniak.com/8618071e5b8c2e9d46a54d7fd2daa2bd476bdad6.png)

Any additional elements will be displayed in the center of the interface and can be modified / deleted.

Refer to [this other guide](https://www.infomaniak.com/en/support/faq/2859) regarding the behavior of these shared folders on the Desktop app.

## Set the default display when starting up

You can choose which homepage to start navigating within k Drive online, from the following 3 options:

1. your personal folder
2. the shared documents folder
3. favorites (which groups the documents added as favorites by your user)

To access k Drive and modify the homepage:

1. [Click here](https://ksuite.infomaniak.com/kdrive) to access the management of your product on the Infomaniak Manager ([need help?](https://www.infomaniak.com/en/support/faq/1990#nav)).
2. Click on the **Settings** icon in the top right corner.
3. Check or select the relevant k Drive from the dropdown menu in the left sidebar.
4. Click on **General** in the left sidebar.
5. Choose the page that should be displayed by default when arriving at the homepage:

![image](https://faq.storage5.infomaniak.com/86b81032905e385204ab22eb2c8b251633599349.png)
