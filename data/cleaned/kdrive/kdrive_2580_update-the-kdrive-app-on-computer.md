# Update the k Drive app on computer

Source: https://www.infomaniak.com/en/support/faq/2580/update-the-kdrive-app-on-computer

---

This guide explains how to check and update the version of the desktop app [k Drive](https://infomaniak.com/gtl/kdrive) (desktop application on macOS / Windows / Linux).

## Access the installed version information…

### … on macOS / Windows / Linux

To identify the version number of the k Drive application:

1. Left-click on the desktop app icon in the notification area of your computer (top right on macOS, bottom right on Windows and a double left click in the taskbar on Linux).
2. Click on the icon **⋮** at the top right of the application, then on **Preferences**:

![image](https://faq.storage5.infomaniak.com/21caeb0b0f41aed7f2e75423ca1549c40b03a4d5.png)

or directly on **Preferences** if the k Drive window is already open:

![image](https://faq.storage5.infomaniak.com/086842e149e9fb5aaef79645b7344c7ab1f1cd0b.png)

3. Scroll all the way down and under the **Version** category, the version currently installed on your computer is indicated:

![image](https://faq.storage5.infomaniak.com/ce06c69b729e205c3683230b583cbe82d7289e7e.png)

## Update the installed version

### … on macOS / Windows

With each new version of the k Drive application offered by Infomaniak, a message will appear when the software is first opened after a restart or a few minutes later if it is not restarted, offering the possibility to install the update automatically.

If this is not the case:

- Refer to the steps above and **click on the displayed button offering the update**:

![image](https://faq.storage5.infomaniak.com/e6947b8a8b6a71a05486ae907570055af58f8833.png)

If the button is missing or the app version is too old:

1. **Download the latest version**[from the official page](https://infomaniak.com/gtl/apps.kdrive) (the number of the most recent version is displayed in the file name):

![image](https://faq.storage5.infomaniak.com/efa4319d11e2ec814179c82447894a8a3657e670.png)

2. If this version number is more recent than your current version, let the download complete.
3. In the meantime, uninstall your application without touching the folder containing your synchronized files and especially [without moving it](https://www.infomaniak.com/en/support/faq/2856).
4. Install the downloaded new version.
