# Manage and manipulate your files on k Drive

Source: https://www.infomaniak.com/en/support/faq/2873/manage-and-manipulate-your-files-on-kdrive

---

This guide details some of the operations that can be performed with data stored on [k Drive](https://infomaniak.com/gtl/kdrive) Infomaniak.

## Add to favorites / follow a file

Favorites are synchronized between the Web app **k Drive** Infomaniak (online service [ksuite.infomaniak.com/kdrive](https://ksuite.infomaniak.com/kdrive))…

![image](https://faq.storage5.infomaniak.com/30458c449c8390fbfd6565d49d768d4e41ce1bb3.gif)

… and the mobile app (application for iOS / Android smartphone or tablet):

![image](https://faq.storage5.infomaniak.com/d636aa983466131245736ad620add9a32485bb1f.gif)

### On the k Drive Web app

To add a file or folder to favorites in the Web app **k Drive** Infomaniak (online service [ksuite.infomaniak.com/kdrive](https://ksuite.infomaniak.com/kdrive)):

1. [Click here](https://ksuite.infomaniak.com/kdrive) to access the Web app **k Drive** Infomaniak (online service [ksuite.infomaniak.com/kdrive](https://ksuite.infomaniak.com/kdrive)).
2. Select a file to mark as a favorite and click on the icon **☆**:

![image](https://faq.storage5.infomaniak.com/143404f4eae690c64f12e6624d3c729dbb8c4343.png)

3. You can also add multiple files to favorites using the top menu…

![image](https://faq.storage5.infomaniak.com/448c8f1f92d02c2e739dc8a399afc3723e3c13c9.png)

4. … or click on the action menu **⋮** located to the right of the item in question:

![image](https://faq.storage5.infomaniak.com/594cd594435fde80dee145683061db80d66e62e6.png)
