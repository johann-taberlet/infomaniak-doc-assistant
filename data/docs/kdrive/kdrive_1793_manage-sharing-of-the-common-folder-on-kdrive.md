# Manage the sharing of the organization's kDrive Folders

Source: https://www.infomaniak.com/en/support/faq/1793/manage-sharing-of-the-common-folder-on-kdrive

---

This guide illustrates the different types of sharing that can be done within the shared folder named “**Organization Folders**” on [kDrive](https://infomaniak.com/gtl/kdrive) and explains how to **limit access to the folder** if certain users should not have access to everything already in it. It is very easy to modify a share at any time.

> **Note:** Also see [this other guide](https://www.infomaniak.com/en/support/faq/2859) about folder sharing.

## Switching from a simple share to a kSuite invitation

Imagine…

### A. Result of a share without the need for the invited user to sign up

A folder present **in Organization Folders** is first **shared with a completely external new user** to this kDrive and to Infomaniak, via a **public share link**:

1. Right-click on the folder or subfolder in question.
2. Choose the **Share** item:

3. Then:Stay on the first tab.Activate the public share link.Adjust the security settings according to your needs.Copy the link to send it, or send it directly from the window:

Therefore, the user who views this public link gets **this type of view**:

- They can **navigate**, **view**, and **download** files, including to their own kDrive, all in *read-only* mode:

![image](https://faq.storage5.infomaniak.com/64b50075d74a8b30b03540c64e5b82149b3d31c7.png)

### B. Result of a share with sign-up (not counted in kSuite)

A folder present **in Organization Folders** is now **shared with an “external” type of user who will need to sign up** or at least log in to their account if they already have one, and accept the invitation.

> **Note:** **The user must be completely external** to Infomaniak or at least **not have an email address on the Mail Service linked to the possible kSuite from which the kDrive in question depends**.

To do this, you must this time choose the **second sharing tab**:

1. Right-click on the folder or subfolder in question.
2. Choose the **Share** item.
3. Click on the **second tab**.
4. Enter the **email address** of the user concerned.
5. Click to **add** (the operation can be performed for multiple users at the same time):

![image](https://faq.storage5.infomaniak.com/f8414afb40b49f0ac2cb4d352f8d526327662e8d.png)

6. Regarding the freedom given to the user to modify or not the part of the kDrive to which he will have access, the choice made here is that of *Modify*.
7. Click on **Send the invitation**:

![image](https://faq.storage5.infomaniak.com/d4ae5e14ce65980e3cd5c4e29d8279a4500d075e.png)

8. This choice (see point 6 above) will allow you to **invite** this person as an **external user** first — read below for the complete kSuite invitation):

![image](https://faq.storage5.infomaniak.com/e9b17e98bf94dc826bfabf2b759fa77d1d9cd86f.png)

9. The administrator can see the pending request and resend the invitation if necessary:

![image](https://faq.storage5.infomaniak.com/2bb0d0237dbac0070e5d6d272a6ef0f1442e35da.png)

10. The invited person receives an email to register as an Infomaniak user:

![image](https://faq.storage5.infomaniak.com/62fe428e4c62a264471aa0c7d55ad12e29abbaa1.png)

11. The person fills in the form with their details and chooses a password, **their email address is pre-filled**, this will be their **Infomaniak account identifier**:

![image](https://faq.storage5.infomaniak.com/a4880abca912bf3fb9ebc5d6b38cc3e6280d3f06.png)

12. Once registration is complete, a simplified kDrive interface with “**Shared with me**” on the left allows access to the shared content (only the initially shared content, **and not the entire shared folder**) and to modify it:

![image](https://faq.storage5.infomaniak.com/65f40b97c53381d7c05cbee1301681304293c1dd.png)
The possible modifications made are common to all users who have access to this part of this kDrive.The user does not have any private/personal space.They can install the kDrive mobile/desktop app and log in, but no data will be visible: The user will necessarily have to go through the online interface to access the files shared with them, as long as they are an external user, even if they have a personal kDrive!On the kDrive administrator dashboard, users are presented as follows:

### D. Restrict user access

Once registration is complete, the new user's kDrive interface usually allows access to **all** content that has been shared with all kDrive users.

> **Note:** **The Organization's Folders are common folders but**[do not necessarily imply](https://www.infomaniak.com/en/support/faq/2501)**that all kDrive users have access to them.**

![image](https://faq.storage5.infomaniak.com/b565555e028982504d182527e4ae26b9d22444ab.png)

If the invited user sees nothing in this shared folder, check **from the administrator account** if the sharing rights have been expanded to all kDrive users:

![image](https://faq.storage5.infomaniak.com/064091abd95f3da3315ff09285c1400cccf09866.png)

 

Conversely, it is also possible: if the new kSuite user accesses all **Organization Folders** and this is not desired, the administrator must modify the sharing of the parent folder (the root folder of the shared folder, for example):

1. Right-click on the parent folder, select the **Share** item, then choose the second sharing tab and click **Manage** on the right to select the removal of the share (the effect is recursive and applies to all items contained within the parent folder):

![image](https://faq.storage5.infomaniak.com/01889faa021e50e084cda2feaa808bb8523dc0d8.gif)

 
2. Then share again, but more restrictively, from the folder in question:

![image](https://faq.storage5.infomaniak.com/ec93d6798948fa911c20b753965fb26de6039293.png)

 
3. Check the access column in the kDrive tree:

![image](https://faq.storage5.infomaniak.com/69213ee452b4a310d7997965e3ffebd62c6f7284.png)

4. And here is the user who now sees only part of the **shared** folder:

![image](https://faq.storage5.infomaniak.com/6ccaa28aa1cb5ac5eddb23263003d7e3c27651b5.png)

5. And this time, if the user installs the kDrive app, they can choose the kDrive in question:

![image](https://faq.storage5.infomaniak.com/b94f10cedb4c8aa91d4d31add676572ddcadbb36.png)

and access the files on the computer:

![image](https://faq.storage5.infomaniak.com/202ab07e2d71028d63f4b3b7367cbc70fde98975.png)
