# Create a kChat message reminder

Source: https://www.infomaniak.com/en/support/faq/1664/create-a-kchat-message-reminder

---

This guide explains how to get a notification to review a specific [kChat](https://infomaniak.com/gtl/kchat) message at a set time.

**⚠ Available with:**

******without custom scheduling*

## Remind a kChat message at a specific time

To review a message using a future notification:

1. Hover over the message to be reminded and select the additional actions icon **•••**in the top right corner:

![image](https://faq.storage5.infomaniak.com/c7d70160ab601734cc8b2c3351b0038f49831f36.png)

2. Click on **Remind**and choose the desired time to be notified:

![image](https://faq.storage5.infomaniak.com/8ee63b95303a213306366f7656260f71882de464.png)

3. You will then receive a notification at the chosen time for the kChat message, from kChat Bot (Euria), with the necessary information to view the message, set a later reminder, cancel any other reminders, etc.
