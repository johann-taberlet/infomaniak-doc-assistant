# Import data to kDrive (iOS)

Source: https://www.infomaniak.com/en/support/faq/2796/import-data-to-kdrive-ios

---

This guide explains how to transfer files from an iPhone to an [kDrive](https://infomaniak.com/gtl/kdrive) Infomaniak.

### Prerequisites

- Have a [kDrive](https://infomaniak.com/gtl/ksuite.kdrive) or [kSuite](https://infomaniak.com/gtl/ksuite) offer.
- [Install](https://ksuite.infomaniak.com/all?global-settings=user-apps) the mobile app **kDrive** (application for iOS smartphone or tablet).

## Manually send data to kDrive iOS (iPhone, iPad)

To do this:

1. Select the data you want to share on kDrive.
2. Click on the iPhone share icon:

![sign](https://faq.storage.infomaniak.com/658a970e7a1c60.67123906PNG)

3. Choose kDrive from the options offered:

![sign](https://faq.storage.infomaniak.com/658a972b9134f1.91244715PNG)

4. Select the kDrive and the backup location - if this does not suit you, press it to change the storage folder:

![sign](https://faq.storage.infomaniak.com/658a9741a44ff7.23618562PNG)

5. Choose another folder or **create a new folder**:

![sign](https://faq.storage.infomaniak.com/658a97a393c330.02729307PNG)

6. Determine the type of folder to create (shared folder with kDrive users or personal & private folder):

![sign](https://faq.storage.infomaniak.com/658a98190c2937.39675592PNG)

7. Name the folder, choose the possible shared access and then press the blue button to create the folder:

![sign](https://faq.storage.infomaniak.com/658a985f5f7ae7.84251780PNG)

8. Press the newly created folder to select it as the location:

![sign](https://faq.storage.infomaniak.com/658a9aed0681f3.10292578png)

9. Create a possible subfolder in it or **validate** the chosen location with the blue button:

![sign](https://faq.storage.infomaniak.com/658a98c93fbbd2.02754161PNG)

10. Press the blue button to start **sending** your files to kDrive:

![sign](https://faq.storage.infomaniak.com/658a98fc5b8632.89536745PNG)

11. It is possible to follow the progress of the transfer to kDrive:

![sign](https://faq.storage.infomaniak.com/658a992d54c261.69573495PNG)

12. The upload takes place in the background:

![sign](https://faq.storage.infomaniak.com/658a99731c5280.51328412PNG)

Once the files are uploaded, you will find them on all devices connected to kDrive…

- … instantly on the Web app **kDrive** (online service [ksuite.infomaniak.com/kdrive](https://ksuite.infomaniak.com/kdrive)).
- … after downloading the list of these new files to the devices where the **kDrive** desktop app (desktop application on macOS / Windows / Linux) is installed.
