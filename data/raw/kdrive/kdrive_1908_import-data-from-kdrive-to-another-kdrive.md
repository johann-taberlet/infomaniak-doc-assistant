# Import data from kDrive to another kDrive

Source: https://www.infomaniak.com/en/support/faq/1908/import-data-from-kdrive-to-another-kdrive

---

This guide explains how to copy within the desktop app **kDrive** (desktop application on macOS / Windows / Linux) data from a kDrive **to which your Infomaniak user has access** to another kDrive **to which the same Infomaniak user has access**.

### Preamble

- To be the user of multiple Organizations, you must [have been added to them](https://www.infomaniak.com/en/support/faq/1404) and have obtained access rights to the respective kDrives.For example, if the user abc@domain.xyz has within their Organization "ABC" a kDrive "ABC" and is invited to the Organization "VWX" which has granted them access to the kDrive "VWX", they will see 2 kDrives on kdrive.infomaniak.com and will be able to send data from one to the other in 1 click.
- Without being a user of multiple Organizations, it is also possible to copy data but [only by importing an entire kDrive](https://www.infomaniak.com/en/support/faq/2557), without being able to choose specific data.

## kSuite Configuration

If you are in a kSuite environment (the kDrive app displayed within `ksuite.infomaniak.com`, you must ensure that all Organizations are displayed, otherwise you will not be able to switch from one kDrive to another and consequently will not have the copy function to other kDrives:

## Copying data between multiple kDrives

To copy a folder or file to the other kDrive to which you have access from the same user account:

1. [Click here](https://kdrive.infomaniak.com) to access the Infomaniak **kDrive** Web app (online service [kdrive.infomaniak.com](https://kdrive.infomaniak.com/)).
2. Check or select the relevant kDrive in the dropdown menu of the left sidebar.
3. Select, if necessary, the other kDrive from which you want to copy files:

![image](https://faq.storage5.infomaniak.com/f472403eea9104d39ed832606236a80f245dec7f.gif)

 
4. Right-click or click on the action menu **⋮** to the right of the folder or file you want to copy to the other kDrive.
5. Click on **Organize**.
6. Click on **Copy to another kDrive**.
7. Choose the relevant kDrive from the list visible in this same dropdown menu:

![image](https://faq.storage5.infomaniak.com/94013e9803bad93965ac1ce2602c0ebfab8f5c98.png)

8. Choose the destination location (knowing that the shared folder ("**Organization Folders**") cannot receive a file or folder at its root but you can create a subfolder using the **appropriate icon** if the user has the rights).
9. Click on the blue button to start the copy:

![image](https://faq.storage5.infomaniak.com/02fc0176f605292b88115c56005cb1879c2b6a15.png)

> **Note:** The copy is not instantaneous or immediate - please wait several minutes!

If you wish to import all the data contained on the other kDrive **in one go**, refer to [this other guide](https://www.infomaniak.com/en/support/faq/2406) and choose **kDrive** at point **6**.
